# グランドスタッフシミュレーター

空港の地上係員(グランドスタッフ)になって、チェックインカウンターや搭乗ゲートの仕事をするブラウザゲームです。
パソコン・iPad(横向き)と、スマホ(縦向き)で遊べます。

## 仕事の種類

- **チェックインカウンター**:書類・預け荷物・機内持ち込み手荷物(3日目から)・座席を確認して搭乗券を発行
- **搭乗ゲート**:グループ順に案内し、ゲート違いや遅れたお客様に対応
- 昇進すると、カウンターとゲートのあいだに日替わりで仕事が加わる
  - グランドスタッフ(累計1,500点):**予約カウンター**
  - 中堅スタッフ(累計5,000点):**忘れ物センター**
  - チーフ(累計12,000点):**ラウンジ受付**
  - スーパーバイザー(累計20,000点):**手荷物の仕分け**

## ログイン・ランキング(Firebase)

- Googleアカウントでログインすると、記録が Cloud Firestore に保存され、どの端末でも続きから遊べる。ランキング(累計・1日の最高点)にも参加できる
- ログインしなくても遊べる(記録はその端末だけ)
- 設定は `src/js/00-firebase.js` の `FIREBASE_CONFIG`。`null` のあいだはログイン関係のボタンが出ない
- Firestore のルール:`saves/{uid}` は本人だけが読み書き、`ranking/{uid}` はだれでも読めて本人だけが書ける(`icon` は40,000文字まで)
- アイコンは、用意した絵の名前か、画像(128×128のJPEG)の data URL。ほかの人の値は `UIcon.valid` で確かめてから表示する

## ファイルの構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 公開されるゲーム本体(`build.py` が作るので、直接は書き換えない) |
| `src/js/*.js` | ゲームのプログラム。ファイル名の番号順につなげられる |
| `src/style.css` | 見た目 |
| `src/index.html` | HTMLのひな形 |
| `build.py` | `src/` を1つの `index.html` にまとめるスクリプト |

## 更新のしかた

```
python3 build.py
```

を実行すると `index.html` が作り直されます。GitHub に送ると、Render が自動で公開し直します。

## 公開設定(Render の Static Site)

- Branch: `main`
- Build Command: なし
- Publish Directory: `.`
